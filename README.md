# 節拍流星 Pulse Stride

節奏 × 躲避 × 成長 —— 一款單檔 HTML5 音遊風躲避遊戲。無需安裝、無外部素材，打開即玩。

**線上遊玩：** https://hayes314.github.io/pulse-stride/

---

## 玩法

每一拍都會有一顆「節拍流星」落到判定線，把飛梭移到對應車道即可**穿越**得分。
移動時飛梭會自然升起，讓流星從身旁流過 —— 這就是「躲避」的視覺語言。

| 行為 | 結果 |
| --- | --- |
| 對齊流星車道（穿越） | Combo +1、分數倍率最高 ×10、回復相位 |
| 不移動（迴避） | Combo 保持、小幅加分，但拿不到 Combo |
| 撞上障礙 | Combo 中斷、相位 −16 |
| 相位歸零 | 遊戲結束 |

**衝刺**可吞噬障礙物；BPM ≥ 150 時會自動接續下一拍，高速段只需專注方向。

## 內容

- **6 種模式**：冒險、無盡、疾走 15 秒、生存 120 秒、每日挑戰（固定種子）、禪模式（不會失敗）
- **5 級難度**：簡單 → 正常 → 困難 → 極限 → 虛空（依完成世界數解鎖）
- **29 個世界**：各自專屬的和聲、BPM 與災厄組合
- **12 種災厄**：障碼牆、彈幕、閃電、雙生花、鏡像、重力、幻影、磁暴、冰封、延遲、新星、逆流
- **16 套外觀主題**：極光、霓虹街、合成日落、矩陣、櫻花、深海、熔岩、單色、黃金、螢光森林、冰晶、復古掌機、雷暴、糖果、宇宙、夜幕
- **成長系統**：等級與經驗、每日任務、32 項成就、碎片打造 5 種技能（衝刺／相位護盾／流星磁鐵／幻影閃現／時空摺疊）、世界圖鑑
- **3 / 4 / 5 車道**可切換，流速 0.75×–1.85× 可調（依等級提升上限）

## 技術重點

- **單一檔案**：`index.html` 約 4,400 行、218 KB，零依賴、零外部請求
- **音訊全程序化**：WebAudio 即時合成 BGM（鼓、貝斯、和弦墊、琶音、五聲音階跑動）與所有音效；BGM 的 BPM 與遊戲節拍共用同一個時鐘，確保「視覺＝聽覺」
- **任何螢幕比例**：UI 一律以畫面高度 `--h` 為基準縮放；Canvas 依長寬比選擇參考解析度並等比置中，HUD 以 canvas 實際顯示區域定位並扣除瀏海安全區
- **無縫適配**：手機直向／橫向、平板、方形、超寬（到 5,120×1,440）皆測試通過
- **存檔**：localStorage，含版本遷移與損壞資料修正
- **無障礙／體驗**：可關閉震動、閃光、粒子；`prefers-reduced-motion` 自動降低動畫

## 專案結構

```
index.html          # 建置產物（可直接開或部署）
build.sh            # 合併 src/ 產生 index.html
src/
  part-head.html    # <head>、全部 CSS、主題變數
  part-screens.html # 各畫面 HTML
  part-js-a.js      # 資料層：主題、世界、災厄、成就、存檔
  part-js-b.js      # 引擎：WebAudio、圖表生成、物理、渲染
  part-js-c.js      # 應用層：UI、輸入、流程、結果
test/sim.js         # Node DOM/Canvas 模擬器，74 項自動化檢查
```

## 開發

```bash
./build.sh                      # 重新建置 index.html
node test/sim.js                # 跑完整測試（約 4 分鐘）
```

`test/sim.js` 以最小 DOM/Canvas 模擬器在 Node 中實跑遊戲，涵蓋：

- 啟動與所有畫面切換
- 435 組「模式 × 難度 × 世界」完整模擬
- 16 種解析度（320×568 直向 → 5,120×1,440 超寬）
- 3 / 4 / 5 車道
- 鍵盤、滑鼠、觸控手勢、點按車道
- 設定、主題、技能、任務、成就互動
- 存檔遷移與損壞資料
- 12 場隨機輸入壓力測試
